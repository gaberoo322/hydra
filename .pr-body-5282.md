## Summary

`decide.py` emits `wait_or_reap` for a silent-wedged slot, but nothing handled it: the playbook action table had no row (the `wait` row even called it a nap) and the "harness translates" claim was false. This adds a `wait_or_reap` row that runs one deterministic command, `reap.py wait-or-reap <slot> <task_id>`: liveness by child-transcript mtime (live = no-op, dead or missing = forced reap through `run_completion` with tokens from the transcript's final usage line instead of 0). `decide.py` only changes comments and docstrings.

Tier: 3 (operator-review change (docs/operator-playbooks/hydra-autopilot.md, scripts/autopilot/reap.py, scripts/autopilot/decide.py, +4 more))

Merge danger: two-way — scripts, playbook docs and tests only; no persistent schema, external side effect or out-of-repo contract changes, so git revert plus redeploy restores the world.
