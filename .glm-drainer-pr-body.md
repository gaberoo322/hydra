## Summary

The smallest change that exercises every layer of the ADR-0034 §5 trust contract on one real endpoint — the trust-seam tracer bullet.

**Server.** `GET /today/decision-queue` now carries evidence the lookup actually ran alongside its existing `generatedAt`. `getDecisionQueue()` widens from a bare `DecisionItem[]` to `{ items, scanned, sourcesOk }`:
- `scanned` — the pre-dedup raw row count from the fulfilled sub-fetches (proof the lookup reached its sources).
- `sourcesOk` — `true` iff **all three** GitHub sub-fetches settled fulfilled. Any rejection flips it false.

The aggregator is documented "never throws" and all three sub-fetches already degrade to `[]` internally via `Promise.allSettled`/`settledOrEmpty` — so before this change a total sub-fetch failure arrived as `items: []`, bit-for-bit identical to a genuine zero-item day. That is exactly the #3997 `/cycle/history` failure mode this contract closes. The route forwards all three fields; the schema gates them with `.strict()`.

**Client.** `usePageItems` — the single seam ADR-0034 names for the client half — gains two states beyond loading/empty/ready: `stale` (payload older than a caller-declared `freshnessMs` budget, or a later refresh failed while the last-good payload is retained) and `unknown` (no payload, `sourcesOk === false`, or no usable timestamp). The priority order is the ADR-0034 §5 state machine: loading → unknown → stale → empty → ready. `Section.jsx` renders a neutral **UNKNOWN** placeholder (never the red error banner, never the confident empty-state message) and an always-visible "as of" age in every status branch. `OperatorDecisionQueue` opts in with a 5-minute attention budget; unconverted panels (RecentMerges) keep legacy behaviour through additive, optional Section props.

Tier: 3 (operator-review change — `src/api/today-page.ts`, `src/schemas/today-page.ts`, `src/aggregators/decision-queue.ts`, +more; classified via `GET /api/tier`)
