**Slice and decomposition rule.** A dispatch that ships only a slice of its anchor never opens a Refs-only PR, because every PR lane finds a PR through the issue it closes. File a child issue carrying `## Files in scope` and a `Parent design concept: issue-<parent>` line, link it as a native sub-issue, and open the PR with `Closes #<child>` plus `Part of #<parent>`. The child label rule is the `childLabels()` doc comment in `scripts/ci/hydra-prd-render.ts`. Create the child with FLAG labels only, then `advance <child> needs-triage --actor hydra-dev` (from none), then `advance <child> ready-for-agent --reason scoped --rationale "<one line>"`; a child left at zero state is not an epic, so the backstop will not spare it. A parent decomposed into children is advanced to `blocked --reason blocked-by-issue`.
