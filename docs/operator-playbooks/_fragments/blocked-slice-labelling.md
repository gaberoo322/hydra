**Slice and decomposition rule.** A dispatch that ships only a slice of its anchor never opens a Refs-only PR, because every PR lane finds a PR through the issue it closes. File a child issue carrying `## Files in scope` and a `Parent design concept: issue-<parent>` line, link it as a native sub-issue, and open the PR with `Closes #<child>` plus `Part of #<parent>`. The child label rule is the `childLabels()` doc comment in `scripts/ci/hydra-prd-render.ts`. The child's state path, in order: `gh issue create` with `childLabels()` flags only, then `advance <child> needs-triage`, then `advance <child> ready-for-agent --reason scoped --rationale "slice of #<parent>"`, then `gh pr create` with `Closes #<child>`, then `advance <child> needs-qa --evidence pr=<M>`; the worker never advances the child to the claimed state (ADR-0047 D4). A parent decomposed into children is advanced to `blocked --reason blocked-by-issue`.
