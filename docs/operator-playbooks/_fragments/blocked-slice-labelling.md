**Slice and decomposition rule.** A dispatch that ships only a slice of its anchor never opens a Refs-only PR, because every PR lane finds a PR through the issue it closes. File a child issue carrying `## Files in scope` and a `Parent design concept: issue-<parent>` line, link it as a native sub-issue, and open the PR with `Closes #<child>` plus `Part of #<parent>`. The child label rule is the `childLabels()` doc comment in `scripts/ci/hydra-prd-render.ts`. A parent decomposed into children is advanced to `blocked --reason blocked-by-issue`.
